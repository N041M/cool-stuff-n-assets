CRT boot

Read me

Use it as an intro or a splash screen on a retro or terminal-themed site. The glass waits in a box you size on the page, and it grows to fill the window when it powers on. The page must be served by a web server.

Add it to your page

  1. Copy crt.css, term.css and the folders fonts/ and js/ next to your page.

  2. In the head, give the slot the glass waits in a size and position: relative, and load the two stylesheets.

    <style>
  .crt-slot { position: relative; width: 640px; max-width: 100%; aspect-ratio: 7 / 5; }
</style>
<link rel="stylesheet" href="crt.css">
<link rel="stylesheet" href="term.css">

  3. Put the glass in its slot in the body. If your page has a fixed bar at the top, set --crt-top to its height so the full glass starts below it.

    <div class="crt-slot">
  <div class="crt"></div>
</div>

  4. Build the screen in a module script and power it on. screen.powerOff() and screen.degauss() switch it off and bend the picture.

    <script type="module">
  import { Screen } from './js/screen.js';

  const screen = new Screen(document.querySelector('.crt'));
  screen.powerOn();
</script>

The full notes, options and API are in the README.
