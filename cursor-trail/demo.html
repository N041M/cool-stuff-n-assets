Cursor trail

Read me

Use it to give a page a pointer that leaves a short trail of glyphs and sends a ripple out from each click. It draws on a canvas of its own over the whole page and lets every click through. It sets the glyphs in IBM Plex Mono when the page loads that font, and in the system's monospace font otherwise.

Add it to your page

  1. Copy cursor-trail.js next to your page.

  2. Load it at the end of the head.

    <script defer src="cursor-trail.js"></script>

  3. Set the colour of the glyphs.

    :root { --accent: #f0a14a; }

  4. Send a ripple from each click, at the end of the body.

    <script>
  document.addEventListener("click", function (e) {
    if (window.CursorTrail) CursorTrail.pulse(e.clientX, e.clientY);
  });
</script>

  5. Add the class ko to any element the trail should stay off, such as a block of text.

The full notes, options and API are in the README.
