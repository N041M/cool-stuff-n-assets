Cursor trail

Use it to give your page a pointer that leaves a short trail of glyphs, and to answer clicks with a ripple. It draws on a canvas of its own over the page and lets every click through.

Features Trail Ripple Keep it off your text Your own canvas

Trail

Use the trail to give the pointer a little life on a page with plenty of empty space. Move the pointer over the frame, or press Trail to send a wave across it.

What you need

  • cursor-trail.js, 13 KB.
  • --accent on :root for the colour of the glyphs. The trail picks up a change of data-theme on <html>.
  • IBM Plex Mono, if you want the glyphs in that font. Without it they use the system's monospace font.

The code

cursor-trail.js

// The pointer charges every cell along its path, in steps of 10 px, so a
// fast stroke leaves an unbroken trail.
let lastPX = null, lastPY = null;
window.addEventListener("pointermove", function (e) {
  if (!started || reduced) return;
  const x = e.clientX, y = e.clientY;
  if (lastPX === null) inject(x, y, 24, 0.9);
  else {
    const dx = x - lastPX, dy = y - lastPY;
    const steps = Math.min(12, Math.ceil(Math.hypot(dx, dy) / 10));
    for (let i = 1; i <= steps; i++) inject(lastPX + (dx * i) / steps, lastPY + (dy * i) / steps, 24, 0.9);
  }
  lastPX = x;
  lastPY = y;
  wake();
}, { passive: true });
// …
const decay = Math.pow(0.87, dt * 30);
for (let i = 0; i < N; i++) if (E[i] > 0.001) E[i] *= decay; else E[i] = 0;
// …
if (e > 0.06 && m !== 1 && !(m === 2 && RA[idx] < 0.55)) {
  const g = (hash3(c, r, Math.floor(t * 14 + RA[idx] * 10)) * GLYPHS.length) | 0;
  code = (g << 2) | (e > 0.55 ? 0 : e > 0.28 ? 1 : 2);
}

The trail splits the window into cells of 7 × 14 px. Each pointer move charges the cells within 24 px of its path, in steps of 10 px. Every charge falls to 87% each thirtieth of a second, and a cell shows a random glyph while its charge is above 0.06. The drawing loop stops when the last glyph has faded, and nothing is drawn when the system asks for reduced motion.

Add it to your page

  1. Copy cursor-trail.js next to your page.

  2. Load it at the end of the head.

    <script defer src="cursor-trail.js"></script>

  3. Set the colour of the glyphs.

    :root { --accent: #f0a14a; }

  4. To set the glyphs in IBM Plex Mono, copy the fonts folder next to your page and add the font to your CSS. The trail waits up to 1.5 s for it before it starts.

    @font-face {
  font-family: "IBM Plex Mono";
  src: url("fonts/ibm-plex-mono-400-latin.woff2") format("woff2");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

Without a pointer

On a touch screen there is no pointer to move, so the trail stays dark until something draws it. CursorTrail.stroke(x0, y0, x1, y1) lights the cells along a line in CSS pixels. Call it once a frame with the last point and the new one to draw a stroke of your own. A stroke never joins up with the trail of a real pointer moving at the same time. The Trail button in the frame above draws its wave this way.

// A wave across the window, drawn over 1.4 s.
const t0 = performance.now();
let px = null, py = null;
requestAnimationFrame(function step(now) {
  const k = Math.min(1, (now - t0) / 1400);
  const x = innerWidth * (0.08 + 0.84 * k);
  const y = innerHeight * (0.55 + 0.2 * Math.sin(k * Math.PI * 3));
  CursorTrail.stroke(px ?? x, py ?? y, x, y);
  px = x;
  py = y;
  if (k < 1) requestAnimationFrame(step);
});

Ripple

Use the ripple to answer a click with a ring of glyphs that spreads across the page. Click anywhere in the frame, or press Ripple.

What you need

  • cursor-trail.js, set up as under Trail.
  • A click listener that calls CursorTrail.pulse(x, y).

The code

cursor-trail.js

// A pulse is a ring that grows at 950 px a second and fades out over 1.4 s.
function applyPulses(t) {
  for (let p = pulses.length - 1; p >= 0; p--) {
    const pulse = pulses[p];
    const age = t - pulse.t0;
    if (age > 1.4) {
      pulses.splice(p, 1);
      continue;
    }
    const R = age * 950;
    const strength = 0.95 * (1 - age / 1.4);
    for (let r = 0; r < rows; r++) {
      const dy = (r + 0.5) * ch - frac - pulse.y;
      for (let c = 0; c < cols; c++) {
        const d = Math.abs(Math.hypot((c + 0.5) * cw - pulse.x, dy) - R);
        if (d < 34) {
          const idx = r * cols + c;
          const v = strength * (1 - d / 34);
          if (v > E[idx]) E[idx] = v;
        }
      }
    }
  }
}
// …
function pulse(x, y) {
  if (!started || reduced) return;
  pulses.push({ x: x, y: y, t0: performance.now() / 1000 });
  wake();
}

CursorTrail.pulse(x, y) adds a ring at a point on the screen. The ring grows at 950 px a second and fades out over 1.4 s. Each frame it charges the cells within 34 px of its edge, so it lights up in the same glyphs as the trail. The script does not listen for clicks itself, so your page chooses which clicks send a ripple.

Add it to your page

  1. Add the trail as in steps 1 to 3 under Trail.

  2. Send a ripple from each click, at the end of the body.

    <script>
  document.addEventListener("click", function (e) {
    if (window.CursorTrail) CursorTrail.pulse(e.clientX, e.clientY);
  });
</script>

  3. To show the ripple without the trail, stop pointer moves before the trail sees them. This also stops every other pointermove listener on your page.

    <script>
  window.addEventListener("pointermove", function (e) { e.stopImmediatePropagation(); }, true);
</script>

Keep it off your text

Use the class ko to keep the trail and the ripple off headings, buttons and blocks of text, so they stay readable.

What you need

  • Elements with the class ko.

The code

cursor-trail.js

// A .ko element's own cells are 1 and a ragged margin around it is 2. The
// trail never shows on 1 and shows on about half the cells of 2.
function buildMask() {
  mask.fill(0);
  const padX = cw * 1.5;
  const padY = ch * 0.6;
  for (let n = 0; n < koEls.length; n++) {
    const rects = koEls[n].getClientRects();
    for (let k = 0; k < rects.length; k++) {
      const rc = rects[k];
      if (rc.width === 0 || rc.bottom < -ch || rc.top > vh + ch) continue;
      const c0 = Math.max(0, Math.floor((rc.left - padX) / cw));
      const c1 = Math.min(cols - 1, Math.floor((rc.right + padX) / cw));
      const r0 = Math.max(0, Math.floor((rc.top - padY + frac) / ch));
      const r1 = Math.min(rows - 1, Math.floor((rc.bottom + padY + frac) / ch));
      const ic0 = Math.floor(rc.left / cw), ic1 = Math.floor(rc.right / cw);
      const ir0 = Math.floor((rc.top + frac) / ch), ir1 = Math.floor((rc.bottom + frac) / ch);
      for (let r = r0; r <= r1; r++) {
        const inRow = r >= ir0 && r <= ir1;
        for (let c = c0; c <= c1; c++) {
          const idx = r * cols + c;
          if (inRow && c >= ic0 && c <= ic1) mask[idx] = 1;
          else if (mask[idx] === 0) mask[idx] = 2;
        }
      }
    }
  }
}

Before each frame the trail reads the boxes of every .ko element. The cells under an element stay empty. About half of the cells in a margin of 1.5 cells round it stay empty too, which gives the edge a ragged look.

Add it to your page

  1. Add the class ko to each element the trail should stay off.

    <h1 class="ko">Your name</h1>

  2. If your page adds .ko elements after it has loaded, call this afterwards so the trail finds them.

    CursorTrail.refresh();

Your own canvas

Use a canvas of your own to draw the trail behind your content, or to run it over a background that scrolls, such as the page background.

What you need

  • A <canvas id="trail"> in the body.

The code

cursor-trail.js

let canvas = document.getElementById("trail");
if (!canvas) {
  canvas = document.createElement("canvas");
  canvas.id = "trail";
  canvas.setAttribute("aria-hidden", "true");
  canvas.style.cssText = "position:fixed;inset:0;width:100%;height:100vh;height:100lvh;display:block;pointer-events:none;z-index:2147483000";
  (document.body || root).appendChild(canvas);
}
// …
const parallax = Number(canvas.getAttribute("data-parallax")) || 0;
const fill = canvas.getAttribute("data-fill") === "true";
// …
const off = (window.scrollY || 0) * parallax;
// …
if (fill) {
  ctx.fillStyle = colors.bg;
  ctx.fillRect(c * cwD, yD, cwD, chD);
}

The script draws on the element with the id trail, and it adds its own canvas over the page only when there is none. data-parallax is the share of the page scroll the grid of cells moves with, and it is 0 unless you set it. data-fill="true" paints each lit cell in --bg before its glyph, so the trail covers whatever is under it.

Add it to your page

  1. Put the canvas first in the body.

    <canvas id="trail" aria-hidden="true"></canvas>

  2. Fix it behind your content.

    #trail { position: fixed; inset: 0; width: 100%; height: 100vh; pointer-events: none; z-index: 0; }
main { position: relative; z-index: 1; }

  3. Over the page background, put the trail's canvas after the field's and give it both attributes. Its cells then line up with the field's and cover them.

    <canvas id="field" aria-hidden="true"></canvas>
<canvas id="trail" aria-hidden="true" data-parallax="0.5" data-fill="true"></canvas>
