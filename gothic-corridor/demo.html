Read me

Use it as a full-window backdrop behind a title or a landing page. It fills a fixed element under the rest of the page. A still image of the scene shows while it loads and on devices without WebGL2.

Add it to your page

  1. Copy the js/ and shaders/ folders and preview.webp next to your page.

  2. Add the scene as the first element in the body.

    <div class="scene" aria-hidden="true"></div>

  3. Add its CSS. The scene reads the colour of its candle glass from --scene-accent (or --accent when that is not set) and its background from --bg, written as #rrggbb. Content that should sit over the scene needs position: relative.

    :root { --bg: #050608; --scene-accent: #ff5a43; }
body { margin: 0; background: var(--bg); }
.scene {
  position: fixed;
  inset: 0;
  overflow: hidden;
  background: var(--bg) url("preview.webp") 70% 50% / cover no-repeat;
}
.backdrop__canvas {
  position: absolute;
  inset: 0;
  width: 100%;
  height: 100%;
  object-fit: cover;
  opacity: 0;
  transition: opacity 0.9s ease;
}
.scene.is-ready .backdrop__canvas { opacity: 1; }
main { position: relative; }

  4. Load the script in the head.

    <script type="module" src="js/main.js"></script>

  5. Open the page from a web server, for example python3 -m http.server in its folder.

The full notes, options and API are in the README.
