Gothic corridor

Use it as a full-window backdrop behind a title or a landing page. It draws live in WebGL2, and a still image takes its place while it loads and on devices that cannot run it.

Features Scene Still image Behind a page

Scene

Use the scene where a page needs a moving backdrop. It fills the element it is given and stops drawing while that element is off screen or the tab is hidden.

What you need

  • The js/ and shaders/ folders, 104 KB together.
  • preview.webp, the still image, 49 KB.
  • WebGL2 with half-float render targets (EXT_color_buffer_float or EXT_color_buffer_half_float).
  • A web server, because the shaders are fetched.

The code

js/main.js

import { Backdrop } from './backdrop.js';
const SHADERS = [
    'common.glsl',
    'hall.glsl',
    'servitor.glsl',
    'bake.frag',
    'quad.vert',
    'volume.frag',
    'motion.glsl',
    'smoke.glsl',
    'air.frag',
    'censer.glsl',
    'frame.frag',
    'sprite.vert',
    'sprite.frag',
    'bloom.frag',
    'grade.glsl',
    'final.frag',
];
const scene = document.querySelector('.scene');
try {
    const files = Object.fromEntries(await Promise.all(SHADERS.map(async (name) => {
        const res = await fetch(`shaders/${name}`);
        if (!res.ok)
            throw new Error(`${name}: HTTP ${res.status}`);
        return [name, await res.text()];
    })));
    new Backdrop(scene, files).start();
}
catch (err) {
    console.warn('[backdrop]', err);
    scene.classList.add('is-still');
}

main.js fetches the sixteen shader files and hands them to Backdrop, which bakes the hall once and then draws about 30 frames a second into a canvas inside .scene. When a shader fails to load, the scene gets the is-still class and the still image stays.

Add it to your page

  1. Copy the js/ and shaders/ folders and preview.webp next to your page.

  2. Add the scene as the first element in the body.

    <div class="scene" aria-hidden="true"></div>

  3. Add its CSS.

    :root { --bg: #050608; --scene-accent: #ff5a43; }
body { margin: 0; background: var(--bg); }
.scene {
  position: fixed;
  inset: 0;
  overflow: hidden;
  background: var(--bg) url("preview.webp") 70% 50% / cover no-repeat;
}
.backdrop__canvas {
  position: absolute;
  inset: 0;
  width: 100%;
  height: 100%;
  object-fit: cover;
  opacity: 0;
  transition: opacity 0.9s ease;
}
.scene.is-ready .backdrop__canvas { opacity: 1; }
main { position: relative; }

  4. Load the script in the head.

    <script type="module" src="js/main.js"></script>

  5. Open the page from a web server, for example python3 -m http.server in its folder.

Still image

Use the still image so the backdrop is never empty. It shows while the scene loads, and it stays on devices without WebGL2 and on GPUs too slow for the scene.

What you need

  • preview.webp, 49 KB.

The code

demo.html

/* preview.webp is one frame of this scene. It shows while the scene
   bakes, and it stays when the scene cannot run on the device. */
.scene {
  position: fixed;
  inset: 0;
  overflow: hidden;
  background: var(--bg) url("preview.webp") 70% 50% / cover no-repeat;
}
.backdrop__canvas {
  position: absolute;
  inset: 0;
  width: 100%;
  height: 100%;
  object-fit: cover;
  opacity: 0;
  transition: opacity 0.9s ease;
}
.scene.is-ready .backdrop__canvas { opacity: 1; }

js/backdrop.js

}
/** Stop trying and leave the still image under the canvas showing. */
giveUp(err) {
    console.warn('[backdrop]', err);
    this.host.classList.remove('is-ready');
    this.host.classList.add('is-still');
}

The image is the background of .scene, and the canvas fades in over it once the first frame is drawn. When the scene gives up, it removes is-ready, adds is-still and writes the reason to the console.

Add it to your page

  1. To label the still image, add a note after the scene.

    <p class="still-note">Still image</p>

  2. Show the note only when the scene has given up.

    .still-note {
  display: none;
  position: fixed;
  right: 1rem;
  bottom: 1rem;
  margin: 0;
}
.scene.is-still ~ .still-note { display: block; }

  3. If you change --scene-accent, replace preview.webp with a screenshot of your version so that the still image matches the scene.

Behind a page

Put your title or landing page over the scene and give the scene your page's colours.

The code

js/backdrop.js

/** The accent and the page background from the active palette. */
function readColours() {
    const style = getComputedStyle(document.documentElement);
    // The scene's own accent, the glass of the votive candles, comes from
    // --scene-accent when the page sets it, and from --accent otherwise.
    const accent = style.getPropertyValue('--scene-accent').trim() || style.getPropertyValue('--accent');
    return { accent: toLinear(rgb(accent)), bg: rgb(style.getPropertyValue('--bg')) };
}
function rgb(hex) {
    const m = hex.trim().match(/^#([0-9a-f]{2})([0-9a-f]{2})([0-9a-f]{2})$/i);
    if (!m)
        return [0, 0, 0];
    return [parseInt(m[1], 16) / 255, parseInt(m[2], 16) / 255, parseInt(m[3], 16) / 255];
}

The scene reads --bg and --scene-accent from the page once, when it starts, and uses --accent when --scene-accent is not set. A colour written in any form other than #rrggbb comes out black.

Add it to your page

  1. Set the colours on :root. --bg is the background and --scene-accent is the glass of the candles.

    :root { --bg: #050608; --scene-accent: #ff5a43; }

  2. Put your content after the scene and give it position: relative, so that it paints above the fixed scene.

    <div class="scene" aria-hidden="true"></div>
<main>
  <h1>Your title</h1>
</main>
    main { position: relative; }
