Kissifier

Turn a logo, a letter or any outline into a lipstick print. Set how many ridges, lines and weak spots it has, pick the ink and save it as a transparent PNG.

Features On a page Recipes Python tool

On a page

Use the generator on your own page to make prints from your artwork or from shapes your visitors upload. A print about 1000 px wide takes one to two seconds, so it renders in a worker and the page stays responsive.

What you need

  • kissifier.js and render-worker.js.
  • A shape with transparent space around it. Ink thins out toward the outline, so a shape that touches the edge of its image keeps full ink there.
  • A web server. The worker does not run when the page is opened straight from the file.

The code

kissifier.js

// Crease direction at a point: across each lip, fanning toward the corners, pointing away
// from the mouth.
function across(x, y, b, out) {
  const vx = (x - b.x0 - b.w / 2) / (b.w / 2) ** 2;
  const vy = (y - b.y0 - b.h / 2) / (0.3 * b.h) ** 2;
  const n = Math.hypot(vx, vy) + 1e-9;
  out[0] = vx / n;
  out[1] = vy / n;
  return out;
}

Ridges, lines and the fine wrinkles all follow this field. It points away from a line through the middle of the shape. On a kiss that line is the mouth. On a shape without a mouth it is where the creases meet.

render-worker.js

importScripts("kissifier.js");

onmessage = ({ data: { id, alpha, width, height, recipe, color } }) => {
  const print = Kissifier.render(Kissifier.shape(alpha, width, height), recipe, color);
  postMessage({ id, width: print.width, height: print.height, data: print.data }, [print.data.buffer]);
};

The worker gets the shape's mask and a recipe and sends back the print's pixels. A hole in the shape, such as the inside of an o, is treated as the mouth and gets a pale band along it.

Add it to your page

  1. Copy kissifier.js and render-worker.js next to your page, and load kissifier.js.

    <script src="kissifier.js"></script>

  2. Read the shape from a transparent image and add ridges, lines and weak spots to a new recipe.

    const canvas = document.createElement("canvas");
canvas.width = img.naturalWidth;
canvas.height = img.naturalHeight;
const ctx = canvas.getContext("2d");
ctx.drawImage(img, 0, 0);
const px = ctx.getImageData(0, 0, canvas.width, canvas.height).data;
const alpha = new Float32Array(canvas.width * canvas.height);
for (let i = 0; i < alpha.length; i++) alpha[i] = px[4 * i + 3] / 255;

const shape = Kissifier.shape(alpha, canvas.width, canvas.height);
const recipe = Kissifier.addFeatures(shape, Kissifier.newRecipe(1), { ridges: 80, lines: 50, weak: 3 }, 2);

  3. Render it in the worker and draw the print on a canvas.

    const worker = new Worker("render-worker.js");
worker.onmessage = ({ data }) => {
  const out = document.querySelector("canvas.print");
  out.width = data.width;
  out.height = data.height;
  out.getContext("2d").putImageData(new ImageData(data.data, data.width, data.height), 0, 0);
};
worker.postMessage({ id: 1, alpha: shape.A, width: shape.W, height: shape.H, recipe, color: "#7a1e1e" });

Recipes

A recipe lists every ridge, line and weak spot in a print, so the same recipe on the same shape always gives the same print. Call addFeatures again to add more and keep the ones already there. Shorten a list to remove the newest.

{
  "seed": 1,
  "pressure": 1.1,
  "ridges": [{ "at": [0.079, 0.5508], "width": 0.0039, "seed": 109342232 }],
  "lines": [{ "at": [0.3341, 0.903], "width": 0.0036, "length": 0.069, "branches": 3, "seed": 411772336 }],
  "weak": [{ "at": [0.72, 0.8], "radius": 0.0647, "strength": 0.5566 }]
}
  • A ridge is a paper-coloured gap that opens on the outline and tapers to its tip at at.
  • A line is a thin crack centred on at, with branches side cracks.
  • A weak spot is a patch around at where less ink transferred. strength runs from 0 to 1.
  • at is a point as fractions of the shape's bounding box, with x across and y down. width, length and radius are fractions of the box width. pressure sets the overall ink, and seed sets the paper grain.

Python tool

tools/kiss_texture.py is the tool the generator was ported from. It measures a photo of a real print and makes prints with the photo's own texture from the command line. Its recipes have the same format, but it draws prints differently and its random numbers differ, so one recipe gives a different print in each. It needs numpy, Pillow, SciPy and scikit-image.

python tools/kiss_texture.py analyze photo.jpg --out kiss_tex/
python tools/kiss_texture.py add kiss.json --shape shape.png --ridges 100 --lines 10 --box 0,0.5,1,1
python tools/kiss_texture.py add kiss.json --shape shape.png --ridges 25 --lines 70 --box 0,0,1,0.5
python tools/kiss_texture.py add kiss.json --shape shape.png --weak 4
python tools/kiss_texture.py render kiss.json --shape shape.png --texture kiss_tex/ --color "#7A1E1E" --out print.png

render reads the folder that analyze wrote, so run analyze on a photo first. --box x0,y0,x1,y1 keeps new features inside part of the shape and --at x,y puts them at one point. The three add calls above give a print close to the photo, with ridges mostly on the lower lip and cracks mostly on the upper lip.
