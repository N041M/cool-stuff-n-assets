Read me

Use it as an animated background behind a page of text. It draws on a fixed canvas under everything else, scrolls at half the speed of the page and leaves room around the blocks you mark so their text stays readable. It sets the glyphs in IBM Plex Mono when the page loads that font, and in the system's monospace font otherwise.

Add it to your page

  1. Copy field.js next to your page.

  2. Load it at the end of the head.

    <script defer src="field.js"></script>

  3. Put the canvas first in the body.

    <canvas id="field" aria-hidden="true"></canvas>

  4. Fix the canvas behind the page and set the two colours the field reads.

    :root { --bg: #050608; --fg: #eceae4; }
body { margin: 0; background: var(--bg); color: var(--fg); }
#field { position: fixed; inset: 0; width: 100%; height: 100vh; pointer-events: none; z-index: 0; }
main, footer { position: relative; z-index: 1; }

  5. Add the class ko to each block of text the field should leave room around.

  6. For water at the end of the page, put an empty block with data-shore after the footer.

    <div data-shore aria-hidden="true" style="height: 36vh"></div>

The full notes, options and API are in the README.
