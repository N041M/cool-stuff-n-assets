Page background

Use it as an animated background behind a page of text. It draws a slowly moving plot of glyphs on a canvas fixed under your content, scrolls at half the speed of the page and keeps clear of the blocks you mark.

Features The field Water Cut-outs Ruler

The field

Use the field as the background of a whole page, behind your text and images. The frame above shows it on a sample page.

What you need

  • field.js, 20 KB.
  • A <canvas id="field"> fixed behind the page.
  • --bg and --fg on :root. The field redraws when data-theme on <html> changes.
  • IBM Plex Mono, if you want the glyphs in that font. Glyphs it lacks, such as the box-drawing lines, come from the system's monospace font.

The code

field.js

function draw(t) {
  const scrollY = window.scrollY || 0;
  const sceneOff = scrollY * PARALLAX;
  const rowOff = Math.floor(sceneOff / ch);
  frac = sceneOff - rowOff * ch;
  fracD = Math.round(frac * dpr);
  computeTraces(t, rowOff * ch);
  buildMask();

  // A scrolled grid, a resize or a theme change redraws everything. Otherwise
  // only cells whose glyph changed are drawn.
  const full = fullRedraw || rowOff !== lastRowOff || fracD !== lastFracD;
  fullRedraw = false;
  lastRowOff = rowOff;
  lastFracD = fracD;
  ctx.globalAlpha = 1;
  if (full) ctx.clearRect(0, 0, canvas.width, canvas.height);

  for (let r = 0; r < rows; r++) {
    const sr = r + rowOff;
    const sy = (sr + 0.5) * ch;
    const yD = r * chD - fracD;
    const base = r * cols;
    for (let c = 0; c < cols; c++) {
      const idx = base + c;
      const m = mask[idx];
      const x = (c + 0.5) * cw;
      let code;
      if (m === 1 || (m === 2 && RA[idx] < 0.55)) code = -1;
      else if (sy > seaTop) code = waterCell(x, sy - seaTop, t);
      else code = plotCell(c, sr, sy, t);
      if (!full && code === prevCode[idx]) continue;
      prevCode[idx] = code;
      ctx.fillStyle = colors.bg;
      ctx.fillRect(c * cwD, yD, cwD, chD);
      if (code >= 0) ctx.drawImage(atlas, (code >> 7) * cwD, (code & 127) * chD, cwD, chD, c * cwD, yD, cwD, chD);
    }
  }
  drawRuler();
}
// …
const n1 = noise3(x / 260, k * 0.61, t * 0.04);
const n2 = noise3(x / 95, k * 1.37 + 7, t * 0.06);
const env2 = 0.6 + 0.4 * noise3(x / 700, k * 0.23, 5.5);
const h = env2 * (0.6 * Math.max(0, n1) + 0.4 * Math.pow(n2 * 0.5 + 0.5, 3));
traceBuf[n * stride + c] = baseY - amp * h;

The field splits the window into cells of 7 × 14 px and draws each cell from an atlas of glyphs in --fg at seven strengths. Each trace starts from a baseline every five rows and is lifted by two layers of 3D simplex noise whose third axis is time. Every frame works out a glyph for each cell and redraws only the cells whose glyph changed. The grid moves at half the scroll speed, and a machine that takes more than 16 ms a frame gets bigger cells.

When the system asks for reduced motion, the field shows one still moment and redraws it only when the page scrolls or changes.

Add it to your page

  1. Copy field.js next to your page.

  2. Load it at the end of the head.

    <script defer src="field.js"></script>

  3. Put the canvas first in the body.

    <canvas id="field" aria-hidden="true"></canvas>

  4. Fix the canvas behind the page and set the two colours the field reads.

    :root { --bg: #050608; --fg: #eceae4; }
body { margin: 0; background: var(--bg); color: var(--fg); }
#field { position: fixed; inset: 0; width: 100%; height: 100vh; pointer-events: none; z-index: 0; }
main, footer { position: relative; z-index: 1; }

  5. To set the glyphs in IBM Plex Mono, copy the fonts folder next to your page and add the font to your CSS. The field waits up to 1.5 s for it before it starts.

    @font-face {
  font-family: "IBM Plex Mono";
  src: url("fonts/ibm-plex-mono-400-latin.woff2") format("woff2");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

The cursor trail can run on top of the field. Its documentation shows how.

Water

Use the water to end a long page with a footer that sits on a moving sea.

What you need

  • The field, set up as under The field.
  • An empty element with data-shore after your footer.

The code

field.js

// The water reaches the shore spacer exactly when the page is scrolled to
// the end, and stays below it before that.
const maxScroll = Math.max(0, document.documentElement.scrollHeight - window.innerHeight);
seaTop = shoreEl
  ? shoreEl.getBoundingClientRect().top + window.scrollY - maxScroll * (1 - PARALLAX)
  : Infinity;
// …
if (m === 1 || (m === 2 && RA[idx] < 0.55)) code = -1;
else if (sy > seaTop) code = waterCell(x, sy - seaTop, t);
// …
function waterCell(x, dy, t) {
  const ri = Math.floor(dy / ch);
  if (ri === 0) {
    const wc = Math.floor((x + t * 6) / cw);
    return ((hash2(wc >> 2, 3) < 0.85 ? G_H : G_HH) << 7) | 1;
  }
  const sway = Math.sin(t * 0.9 + ri * 0.7) * cw * 1.2;
  const wc = Math.floor((x + t * (4 + ri * 2.5) + sway) / cw);
  const segLen = 2 + ((hash2(ri, 71) * 8) | 0);
  const hs = hash2(Math.floor(wc / segLen), ri + 131);
  const dens = Math.min(0.7, 0.16 + ri * 0.05);
  if (hs < dens) {
    if (hash2(wc, ri + 7) < 0.03) return (G_SQ << 7) | 1;
    return (S.water[((hs / dens) * S.water.length) | 0] << 7) | (ri < 3 ? 3 : ri < 7 ? 2 : 1);
  }
  return -1;
}

The field finds the element with data-shore and works out where its top will be when the page is scrolled to the end. Every cell below that line draws water, so the water rises into view as the reader reaches the bottom. The top row is a surface line, and the rows under it are runs of swell that drift faster the deeper they are.

Add it to your page

  1. Set up the field as under The field.

  2. Put an empty block with data-shore after the footer. Its height sets how much water shows at the end of the page.

    <div data-shore aria-hidden="true" style="height: 36vh"></div>

  3. If your page changes height without a resize, for example after it loads more content, call this so the field measures the page again.

    Field.refresh();

Cut-outs

Use the class ko to keep the field off panels, headings and other blocks of text, so they stay readable without a background of their own.

What you need

  • The field, set up as under The field.
  • Elements with the class ko.

The code

field.js

function buildMask() {
  mask.fill(0);
  const padX = cw * 1.5;
  const padY = ch * 0.6;
  for (let n = 0; n < koEls.length; n++) {
    const rects = koEls[n].getClientRects();
    for (let k = 0; k < rects.length; k++) {
      const rc = rects[k];
      if (rc.width === 0 || rc.bottom < -ch || rc.top > vh + ch) continue;
      const c0 = Math.max(0, Math.floor((rc.left - padX) / cw));
      const c1 = Math.min(cols - 1, Math.floor((rc.right + padX) / cw));
      const r0 = Math.max(0, Math.floor((rc.top - padY + frac) / ch));
      const r1 = Math.min(rows - 1, Math.floor((rc.bottom + padY + frac) / ch));
      const ic0 = Math.floor(rc.left / cw), ic1 = Math.floor(rc.right / cw);
      const ir0 = Math.floor((rc.top + frac) / ch), ir1 = Math.floor((rc.bottom + frac) / ch);
      for (let r = r0; r <= r1; r++) {
        const inRow = r >= ir0 && r <= ir1;
        for (let c = c0; c <= c1; c++) {
          const idx = r * cols + c;
          if (inRow && c >= ic0 && c <= ic1) mask[idx] = 1;
          else if (mask[idx] === 0) mask[idx] = 2;
        }
      }
    }
  }
}

Before each frame the field reads the boxes of every .ko element. The cells under an element stay empty. About half of the cells in a margin of 1.5 cells round it stay empty too, which gives the edge a ragged look.

Add it to your page

  1. Add the class ko to each block of text the field should leave room around.

    <p class="ko">Your text.</p>

  2. If your page adds or moves .ko elements without a resize, call this afterwards.

    Field.refresh();

Ruler

Use the ruler to hang a numbered scale under a fixed top bar.

What you need

  • The field, set up as under The field.
  • A top bar with the class top. A page without one has no ruler.

The code

field.js

barEl = document.querySelector(".top");
barBottom = barEl ? Math.round(barEl.getBoundingClientRect().bottom) : 0;
// …
// A numbered ruler hanging under the top bar. Its ticks line up with the
// grid's dotted columns.
function drawRuler() {
  if (!barEl) return;
  const yD = Math.round(barBottom * dpr);
  ctx.fillStyle = colors.bg;
  ctx.fillRect(0, yD, canvas.width, chD);
  for (let c = 0; c < cols; c++) {
    const m = c % GRID;
    let g = -1;
    if (m === 0) g = G_TICK;
    else if (m === 1 || m === 2) g = GI.get(String(Math.floor(c / GRID) + 1).padStart(2, "0")[m - 1]);
    if (g >= 0) ctx.drawImage(atlas, g * cwD, 3 * chD, cwD, chD, c * cwD, yD, cwD, chD);
  }
  const r = Math.floor((barBottom + frac) / ch);
  for (let c = 0; c < cols && r >= 0 && r < rows; c++) prevCode[r * cols + c] = -9;
}

The field measures the bottom of the .top element when it starts and whenever the page changes size. After the rest of the field it draws one row there, with a tick every six columns and the number of each tick beside it. The ticks line up with the dotted columns of the grid.

Add it to your page

  1. Set up the field as under The field.

  2. Give your top bar the class top.

    <header class="top">Your name</header>

  3. Fix the bar to the top of the window, above the canvas.

    .top { position: fixed; top: 0; left: 0; right: 0; z-index: 10; background: var(--bg); }
