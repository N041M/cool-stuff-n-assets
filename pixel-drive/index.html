Pixel drive

Use it as a moving scene at the top of a landing page or a personal site. It draws an endless generated drive on a canvas fixed under your content and fades into your page colour at the bottom. It needs no libraries.

Features Set up the drive Character look Place, time and weather Rain Snow Fog Football pitch Ještěd UFO Highway sprint Speed Hop Room for your content

Set up the drive

Use this setup to put the drive behind your page. Every section below starts from it, and the frame above shows it with the demo's controls.

What you need

  • The js folder, nine scripts of 377 KB in all.
  • A <canvas id="drive"> fixed behind the page.
  • --bg, --fg and --accent on :root, written as six-digit hex colours. The car takes --accent, and the scene fades into --bg.
  • IBM Plex Mono, for the character look. The drive waits up to 1.5 s for it before it starts.

The code

js/engine.js

// Each plane's depth, its extent above and below its ground line in sprite
// pixels, its distance tint and how much fog adds to it, and its scale in
// pixels per metre.
const PLANE_DEFS = [
  { name: "far", d: 0.1, top: -150, bot: 120, haze: 0.45, fogPlane: 0.9, scale: 0.05, rows: 1 },
  { name: "mid", d: 0.3, top: -150, bot: 3, haze: 0.18, fogPlane: 0.6, scale: 3, rows: 1 },
  { name: "roadside", d: 0.6, top: -150, bot: 4, haze: 0.05, fogPlane: 0.3, scale: 6, rows: 3 },
  { name: "road", d: 1, top: -2, bot: 220, haze: 0, fogPlane: 0.12, scale: 10, rows: 0 },
];
// …
function frame(now) {
  raf = requestAnimationFrame(frame);
  const dt = lastNow ? Math.min(0.1, (now - lastNow) / 1000) : 1 / 60;
  lastNow = now;
  const scroll = window.scrollY || 0;
  // Nothing to do once the scene has scrolled away.
  if (scroll * (1 - PARALLAX) > (E.L.groundEnd * E.P) + 40) {
    if (!E.cleared) {
      ctx.clearRect(0, 0, canvas.width, canvas.height);
      E.cleared = true;
    }
    return;
  }
  E.cleared = false;
  for (let i = 0; i < E.rate; i++) update(dt);
  draw();
}

The scene is four planes of scenery at different depths. Each plane is built in pieces just past the right edge of the screen as the camera moves along the route. Every frame moves the camera, updates the weather and the traffic, and draws the sky, the planes, the car and a fade into --bg. The drive stops drawing once the page has scrolled past the scene.

When the system asks for reduced motion, the drive shows one still picture.

Add it to your page

  1. Copy the js folder next to your page.

  2. Load the nine scripts at the end of the head, in this order.

    <script defer src="js/core.js"></script>
<script defer src="js/art-nature.js"></script>
<script defer src="js/art-built.js"></script>
<script defer src="js/art-beings.js"></script>
<script defer src="js/world.js"></script>
<script defer src="js/weather.js"></script>
<script defer src="js/scenes.js"></script>
<script defer src="js/ascii.js"></script>
<script defer src="js/engine.js"></script>

  3. Put the canvas first in the body.

    <canvas id="drive" aria-hidden="true"></canvas>

  4. Fix the canvas behind the page and set the colours the drive reads. Write all three as six-digit hex colours.

    :root { --bg: #050608; --fg: #eceae4; --accent: #f0a14a; }
body { margin: 0; background: var(--bg); }

main { position: relative; z-index: 1; }

Character look

Use the character look to draw the same scene in text characters, to suit a page set in a monospace font.

What you need

  • The drive, set up as under Set up the drive.
  • IBM Plex Mono. Characters it lacks, such as the box-drawing lines, come from the system's monospace font.

The code

js/engine.js

E.style = params.get("drive") === "ascii" ? "ascii" : "pixel";
E.ascii = E.style !== "pixel";
K.asciiText = E.ascii;
// …
setStyle: function (style) {
  style = style === "pixel" ? "pixel" : "ascii";
  if (style === E.style) return;
  E.style = style;
  E.ascii = style !== "pixel";
  K.asciiText = E.ascii;
  if (!started) return;
  rebuildPlanes();
  backdropKey = "";
  updateLook(0, true);
  if (E.still) drawStill();
},

js/ascii.js reads each picture of the scene in cells of 7 × 14 px. Each cell takes the material that covers most of it and draws the character for that material at one of three strengths. Every row of the scene has one flat tone. Drive.setStyle builds the scenery again in the other look.

Place, time and weather

Use Drive.jump to open the drive on a place, an hour and a weather that suit your page.

What you need

  • The drive, set up as under Set up the drive.

The code

js/engine.js

jump: function (o) {
  o = o || {};
  if (o.seed === undefined) o.seed = seed;
  reset(o);
  E.moonPhase = moonPhaseNow();
  makeStars();
  if (E.still) drawStill();
},

demo.js

// The drive starts once its font has loaded.
(function waitForStart() {
  if (!Drive.seed) return requestAnimationFrame(waitForStart);
  if (feature && feature.jump) Drive.jump(feature.jump);
  if (feature && feature.ufo) jumpToUfo(feature.ufo);
  if (feature && feature.sprint) jumpToSprint(feature.sprint);
  if (feature || embed) Drive.refresh();
  press("data-set-style", Drive.style);
  showSeed();
})();

Drive.jump starts a new route from the options it is given. A weather passed to it holds until the next jump. Without one, the weather drifts toward the climate of each place. The drive starts once its font has loaded, so a page waits for Drive.seed before it jumps.

Every option can be left out.

place
city, highway, bridge, shore (coast), desert, rally, country (farmland), village, forest, mountains or winter.
region
coast, lowland, hills, dry or mountains, for a place that belongs to more than one.
hour
The hour of the day from 0 to 24, for example 19.5 for 19:30.
weather
cover, precip and fog from 0 to 1, temp in °C, and snow and wet from 0 to 1.
seed
The seed of the route. It stays the same when left out.

Add it to your page

  1. Set up the drive as under Set up the drive.

  2. Jump once the drive has started, at the end of the body.

    <script>
  // The drive starts once its font has loaded.
  (function wait() {
    if (!window.Drive || !Drive.seed) return requestAnimationFrame(wait);
    Drive.jump({ place: "village", hour: 21, weather: { precip: 1, temp: -3 } });
  })();
</script>

Rain

Use these options to open the drive on farmland in rain.

What you need

  • The drive, set up as under Set up the drive.

The code

demo.js

rain: { cover: 0.95, precip: 0.8, temp: 10, wet: 1 },
// …
rain: { name: "Rain", jump: { place: "country", hour: 11, weather: WEATHER.rain } },

js/weather.js

// Rain wets the ground within a minute and it dries over five. Snow
// settles over a couple of minutes and melts over four.
const rain = this.precip * K.smooth(0, 2, this.temp);
const snowing = this.precip * (1 - K.smooth(-0.5, 1.5, this.temp));

cover is the share of the sky under cloud, and precip is how hard it rains. Above 2 °C everything that falls is rain. Rain wets the road within a minute, so wet: 1 starts the view with the road already wet.

if (force) {

UFO

Use these options to open the drive at night with a UFO coming down over farmland.

What you need

  • The drive, set up as under Set up the drive.

The code

demo.js

clear: { cover: 0.05, precip: 0, fog: 0 },
// …
ufo: { place: "country", hour: 23, weather: WEATHER.clear, ufo: true },
// …
// The UFO comes down over a pasture in the middle distance once the
// pasture is just right of the middle of the screen. The demo tries routes
// until one has such a pasture ahead, so the UFO comes within seconds.
function jumpToUfo(o) {
  const E = Drive.engine;
  for (let i = 0; i < 200; i++) {
    Drive.jump(Object.assign({}, o, { seed: Math.floor(Math.random() * 4294967295) }));
    const ahead = E.planes.mid.objs.some(function (obj) {
      const x = E.screenXsp(E.planes.mid.d, obj.u) / E.Wsp;
      return obj.ufo && x > 0.5 && x < 1;
    });
    if (ahead) return;
  }
}

ufo: true sends the UFO to the next pasture in the middle distance. It only comes at night in clear air, and the next pasture can be a minute or two away. jumpToUfo tries random seeds until a route has the UFO's pasture in the right half of the screen. A click on the UFO sends it away.

Add it to your page

  1. Set up the drive as under Set up the drive.

  2. Add the function and call it once the drive has started, at the end of the body.

    <script>
  function jumpToUfo(o) {

      const ahead = E.planes.mid.objs.some(function (obj) {
        const x = E.screenXsp(E.planes.mid.d, obj.u) / E.Wsp;
        return obj.ufo && x > 0.5 && x < 1;
      });
      if (ahead) return;
    }
  }
  // The drive starts once its font has loaded.
  (function wait() {
    if (!window.Drive || !Drive.seed) return requestAnimationFrame(wait);

</script>

  3. For touch screens, add a button inside main that sends the UFO away, as a click on it does.

<script>

    const K = window.DriveKit;
    const mid = Drive.engine.planes && Drive.engine.planes.mid;

Highway sprint

Use the sprint to open the drive on a highway where the car weaves through slower traffic.

What you need

  • The drive, set up as under Set up the drive.

The code

demo.js

// The sprint comes once per stretch of highway, when the car is a quarter
// of the way in and the road around it is clear. The view picks a route
// that starts the car just past the quarter, and runs the drive at four
// times its speed until the sprint begins, which takes about three
// seconds. A route whose road does not clear in eight seconds is swapped
// for another.
function jumpToSprint(o) {
  const E = Drive.engine;
  for (let i = 0; i < 200; i++) {
    Drive.jump(Object.assign({}, o, { seed: Math.floor(Math.random() * 4294967295) }));
    const seg = E.route.segAt(E.carWorldX());
    const f = (E.carWorldX() - seg.x0) / (seg.x1 - seg.x0);
    if (seg.place === "highway" && f > 0.26 && f < 0.4) break;
  }
  if (E.still) return;
  Drive.setRate(4);
  const t0 = performance.now();
  (function wait() {
    if (E.pace > 1.3) return Drive.setRate(1);
    if (performance.now() - t0 > 8000) return jumpToSprint(o);
    setTimeout(wait, 100);
  })();
}

The sprint comes once per stretch of highway, when the car is a quarter of the way in and the road around it is clear. jumpToSprint picks a route that starts the car just past that point and runs the drive at four times its speed until the sprint begins. A route whose road does not clear within eight seconds is swapped for another.

  2. Add the function and call it once the drive has started, at the end of the body.

Speed

Use Drive.setRate to run the drive faster, for example to show the light change through a whole day.

What you need

  • The drive, set up as under Set up the drive.

The code

js/engine.js

// How many steps of the scene each frame runs. Above 1 the drive, the
// day and the weather all run faster. Drive.setRate sets it.
rate: 1,
// …
for (let i = 0; i < E.rate; i++) update(dt);
// …
// Runs the drive at 1 to 8 times its speed.
setRate: function (n) {
  E.rate = Math.max(1, Math.min(8, Math.round(n) || 1));
},

Drive.setRate(n) takes a whole number from 1 to 8, and Drive.rate reads it back. Each frame then runs that many steps of the scene, so the day, the weather and the traffic run faster too. A day takes 10 minutes at 1× and 75 seconds at 8×.

Add it to your page

  1. Set up the drive as under Set up the drive.

  2. Add buttons inside main and set the speed from them, at the end of the body.

    <button type="button" data-set-rate="1">1×</button>
<button type="button" data-set-rate="4">4×</button>
<script>
  document.querySelectorAll("[data-set-rate]").forEach(function (button) {
    button.addEventListener("click", function () {
      Drive.setRate(Number(button.getAttribute("data-set-rate")));
    });
  });
</script>

Hop

Use the hop to give visitors something to play with. A click on the car makes it hop, and Drive.hop() does the same from a button.

What you need

  • The drive, set up as under Set up the drive.
  • The cursor trail, if each hop should also send a ripple.

The code

js/engine.js

function hop() {
  if (E.t - hopT > 0.55) hopT = E.t;
  if (window.Field && carRect) window.Field.pulse(carRect.x + carRect.w / 2, carRect.y + carRect.h / 2);
}
// …
window.addEventListener("click", function (e) {
  if (!started || E.still) return;
  if (e.target instanceof Element && e.target.closest("a, button, input, label")) return;
  if (overUfo(e.clientX, e.clientY)) {
    ufo.shoo();
    return;
  }
  if (overCar(e.clientX, e.clientY)) hop();
});

A click on the car starts a hop unless the last one began less than 0.55 s ago. Clicks on links, buttons and form fields are left alone. When the page has window.Field.pulse, each hop also sends a ripple from the car, and the cursor trail provides it. Under reduced motion the car does not hop.

Add it to your page

  1. Set up the drive as under Set up the drive.

  2. For touch screens, add a button inside main that makes the car hop, at the end of the body.

    <button type="button" data-hop>Hop</button>
<script>
  document.querySelector("[data-hop]").addEventListener("click", function () {
    Drive.hop();
  });
</script>

  3. To send a ripple from the car on each hop, copy cursor-trail.js from the cursor trail next to your page and load it after the drive.

    <script defer src="cursor-trail.js"></script>

Room for your content

Use these hooks when your page has a heading or a panel over the scene and the car should not drive behind it.

What you need

  • The drive, set up as under Set up the drive.
  • An element with data-hero round the top of your page, with your blocks in .hero-inner.
  • A fixed .top bar, if your page has one.

The code

js/engine.js

heroEl = document.querySelector("[data-hero]");
heroH = heroEl ? heroEl.offsetHeight : vh;
const bar = document.querySelector(".top");
barBottom = bar ? Math.round(bar.getBoundingClientRect().bottom) : 56;
// …
heroBlocks = heroEl
  ? Array.from(heroEl.querySelectorAll(".hero-inner > *")).map(function (el) {
      const r = el.getBoundingClientRect();
      return { left: r.left, right: r.right, top: r.top + window.scrollY, bottom: r.bottom + window.scrollY };
    }).filter(function (b) { return b.right > b.left; })
  : [];
// …
// The road sits at 80% of the hero, or lower if the car would otherwise
// drive behind the hero text above it.
let clear = 0;
for (let i = 0; i < heroBlocks.length; i++) {
  const b = heroBlocks[i];
  if (b.right > carXcss - 8 && b.left < carXcss + carCss + 8) clear = Math.max(clear, b.bottom);
}
const roadCss = Math.max(heroH * 0.8, clear ? clear + 14 + carHCss - 13 * E.P : 0);
// …
L.skyTop = Math.ceil((barBottom + 6) / E.P);

The scene is as tall as the data-hero element, or as the window when there is none. The road sits at 80% of that height and moves lower when a block in .hero-inner stands above the car. The sky starts 6 px below a .top bar, or 56 px from the top without one. The drive measures these when it starts and whenever the page changes size.

Add it to your page

  1. Set up the drive as under Set up the drive.

  2. Mark the top of your page with data-hero and put its blocks in .hero-inner.

    <main>
  <section class="hero" data-hero>
    <div class="hero-inner">
      <h1>Your name</h1>
      <p>One line about your work.</p>
    </div>
  </section>
</main>

  3. Give the section its height. The road sits at 80% of it.

    .hero { box-sizing: border-box; min-height: 100vh; padding: 6rem 2rem 120px; }

  4. If you show or hide blocks in .hero-inner without a resize, call this afterwards so the road moves.

    Drive.refresh();
