Read me

Use it to make a heading, a name or a row of labels resolve out of random characters when the page loads or when someone clicks them. It works on the text already in your markup and puts it back exactly when a run ends. It needs no CSS and no font.

Add it to your page

  1. Copy scramble.js next to your page.

  2. Load it at the end of the head.

    <script defer src="scramble.js"></script>

  3. Mark the text to scramble with data-scramble. An element is scrambled when it holds only text, so a marked container scrambles each such element inside it.

    <h1 data-scramble>Your name</h1>
<nav data-scramble><a href="#work">Work</a> <a href="#contact">Contact</a></nav>

  4. Run it when the page loads and on every click, at the end of the body.

    <script>
  addEventListener("DOMContentLoaded", function () {
    Scramble.installClickHandler();
    Scramble.all("[data-scramble]");
  });
</script>

The full notes, options and API are in the README.
