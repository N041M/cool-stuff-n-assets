Text scramble

Use it to make headings, names and labels resolve out of random characters when the page loads, when they are clicked or when they scroll into view. It works on the text already in your markup and needs no CSS and no font.

Features On load On click On first sight Streamed reveal Copy button

On load

Use it on a heading or a name at the top of the page, so the text resolves as the page appears.

What you need

  • scramble.js, 7 KB.

The code

scramble.js

const pool = POOLS[(Math.random() * POOLS.length) | 0];
const n = orig.length;
const total = SPREAD_BASE_MS + Math.random() * SPREAD_RANGE_MS;

const order = Array.from({ length: n }, function (_, i) { return i; });
if (Math.random() < REVERSE_CHANCE) order.reverse();
const resolveAt = new Array(n);
order.forEach(function (charIndex, k) {
  resolveAt[charIndex] =
    (k / Math.max(1, n - 1)) * total * SWEEP_SHARE + Math.random() * total * JITTER_SHARE;
});

const start = performance.now();
// If something else rewrites the node mid-run, stop instead of finishing
// over the new text.
let written = orig;
interval = setInterval(function () {
  if (node.nodeValue !== written) {
    stop();
    return;
  }
  const elapsed = performance.now() - start;
  let out = "";
  let done = true;
  for (let i = 0; i < n; i++) {
    const c = orig[i];
    if (/\s/.test(c)) {
      out += c;
      continue;
    }
    if (elapsed >= resolveAt[i]) out += c;
    else {
      done = false;
      out += randomFrom(pool);
    }
  }
  node.nodeValue = out;
  written = out;
  if (done) {
    node.nodeValue = orig;
    stop();
  }
}, TICK_MS);

Each character gets a time to resolve, spread from left to right across 620 to 800 ms with some jitter. Every 38 ms the characters that have not resolved change to random glyphs from one pool, and at the end the element gets its exact original text back.

Add it to your page

  1. Copy scramble.js next to your page.

  2. Load it at the end of the head.

    <script defer src="scramble.js"></script>

  3. Mark the text with data-scramble. An element is scrambled when it holds only text, so a marked container scrambles each such element inside it.

    <h1 data-scramble>Your name</h1>
<nav data-scramble><a href="#work">Work</a> <a href="#contact">Contact</a></nav>

  4. Run it when the page loads, at the end of the body.

    <script>
  addEventListener("DOMContentLoaded", function () {
    Scramble.all("[data-scramble]");
  });
</script>

On click

Use it on labels, tags or links, so they scramble again when someone clicks them.

What you need

  • scramble.js, 7 KB.

The code

scramble.js

function installClickHandler() {
  document.addEventListener("click", function (event) {
    const target = event.target;
    if (!(target instanceof Element)) return;
    if (!target.closest("[data-scramble]")) return;
    if (target.children.length !== 0) return;
    scrambleElement(target, CLICK_DELAY_MS);
  });
}

One listener on the document handles every click. It scrambles the clicked element when the element holds only text and sits inside [data-scramble], and it ignores a second click while a run is still going.

Add it to your page

  1. Copy scramble.js next to your page and load it at the end of the head.

    <script defer src="scramble.js"></script>

  2. Mark the labels with data-scramble.

    <p data-scramble><span>2026</span> <span>Prague</span> <span>v1.0</span></p>

  3. Install the click handler at the end of the body.

    <script>
  addEventListener("DOMContentLoaded", function () {
    Scramble.installClickHandler();
  });
</script>

On first sight

Use it on dates, figures or captions further down a long page, so they resolve when the reader reaches them.

What you need

  • scramble.js, 7 KB.

The code

demo.js

// Labels further down resolve the first time they scroll into view.
const seen = new WeakSet();
const io = new IntersectionObserver(function (entries) {
  entries.forEach(function (e) {
    if (!e.isIntersecting || seen.has(e.target)) return;
    seen.add(e.target);
    io.unobserve(e.target);
    Scramble.leaves(e.target).forEach(function (el, i) {
      if (el.getClientRects().length) Scramble.element(el, (i % 5) * 40);
    });
  });
}, { threshold: 0.6 });
document.querySelectorAll("main section:not(.hero) [data-scramble]").forEach(function (el) { io.observe(el); });

An IntersectionObserver watches each marked element. The first time 60% of one is on screen, every element inside it that holds only text scrambles, 40 ms after the one before and starting over every five.

Add it to your page

  1. Copy scramble.js next to your page and load it at the end of the head.

    <script defer src="scramble.js"></script>

  2. Mark the text with data-scramble.

    <p data-scramble>Feb – Jul 2025</p>
<p data-scramble>2022 – present</p>

  3. Watch the marked elements, at the end of the body.

    <script>
  addEventListener("DOMContentLoaded", function () {
    const seen = new WeakSet();
    const io = new IntersectionObserver(function (entries) {
      entries.forEach(function (e) {
        if (!e.isIntersecting || seen.has(e.target)) return;
        seen.add(e.target);
        io.unobserve(e.target);
        Scramble.leaves(e.target).forEach(function (el, i) {
          if (el.getClientRects().length) Scramble.element(el, (i % 5) * 40);
        });
      });
    }, { threshold: 0.6 });
    document.querySelectorAll("[data-scramble]").forEach(function (el) { io.observe(el); });
  });
</script>

Streamed reveal

Use it to show a message, an answer or a status line as if it were arriving. The text streams in behind a short run of random characters.

What you need

  • scramble.js, 7 KB.

The code

scramble.js

// Reveal a known string through a trailing scrambled window. `onFrame` gets
// the text to display, and the last frame is always the exact string.
function streamReveal(text, onFrame, onDone) {
  if (!isMotionEnabled()) {
    onFrame(text);
    if (onDone) onDone();
    return function () {};
  }
  const pool = POOLS[(Math.random() * POOLS.length) | 0];
  const n = text.length;
  const advance = revealAdvanceFor(n);
  let front = 0;
  let interval = null;
  const tick = function () {
    front = Math.min(front + advance, n + STREAM_WINDOW_CHARS);
    const resolved = Math.max(0, Math.min(n, front - STREAM_WINDOW_CHARS));
    let out = text.slice(0, resolved);
    for (let i = resolved; i < Math.min(n, front); i++) {
      const c = text[i];
      out += /\s/.test(c) ? c : randomFrom(pool);
    }
    onFrame(out);
    if (resolved >= n) {
      clearInterval(interval);
      interval = null;
      if (onDone) onDone();
    }
  };
  tick();
  if (front - STREAM_WINDOW_CHARS < n) interval = setInterval(tick, TICK_MS);
  return function () {
    if (interval !== null) clearInterval(interval);
    interval = null;
  };
}

Each 38 ms tick moves the front forward by at least five characters, and by more in a long text, so that a long text takes about 1.1 s. The 14 characters behind the front are random glyphs, and everything before them is the real text.

Add it to your page

  1. Copy scramble.js next to your page and load it at the end of the head.

    <script defer src="scramble.js"></script>

  2. Add an element for the text and a button that starts it.

    <p data-reply aria-live="polite"></p>
<button type="button" data-stream>Reveal</button>

  3. Stream the text in when the button is pressed, at the end of the body.

    <script>
  addEventListener("DOMContentLoaded", function () {
    const reply = document.querySelector("[data-reply]");
    let cancel = function () {};
    document.querySelector("[data-stream]").addEventListener("click", function () {
      cancel();
      cancel = Scramble.streamReveal("Thanks for writing. I am away until Monday and will answer your message then.", function (text) { reply.textContent = text; });
    });
  });
</script>

Copy button

Use it on a button that copies an email address or a code, so its label scrambles into “Copied”.

What you need

  • scramble.js, 7 KB.
  • The Clipboard API, which works on HTTPS pages and on localhost.

The code

demo.js

// The copy button scrambles "Copied" once the address is on the clipboard.
document.querySelectorAll("[data-copy]").forEach(function (button) {
  let timer = 0;
  button.addEventListener("click", function () {
    const done = function () {
      button.classList.add("done");
      Scramble.leaves(button.querySelector(".copy-done")).forEach(function (el) { Scramble.element(el); });
      clearTimeout(timer);
      timer = setTimeout(function () { button.classList.remove("done"); }, 2200);
    };
    if (navigator.clipboard && navigator.clipboard.writeText) navigator.clipboard.writeText(button.getAttribute("data-copy")).then(done, function () {});
  });
});

The button holds both labels, and CSS shows one of them. Once the text is on the clipboard, the button gets the done class and its “Copied” label scrambles, and 2.2 s later the button goes back.

Add it to your page

  1. Copy scramble.js next to your page and load it at the end of the head.

    <script defer src="scramble.js"></script>

  2. Add the button with both labels. data-copy holds the text to copy.

    <button type="button" class="copy" data-copy="hello@example.com">
  <span class="copy-idle">Copy</span>
  <span class="copy-done">Copied</span>
</button>

  3. Show one label at a time.

    .copy .copy-done, .copy.done .copy-idle { display: none; }
.copy.done .copy-done { display: inline; }

  4. Copy the text and scramble “Copied” when the button is pressed, at the end of the body.

    <script>
  addEventListener("DOMContentLoaded", function () {
    document.querySelectorAll("[data-copy]").forEach(function (button) {

        };
        if (navigator.clipboard && navigator.clipboard.writeText) navigator.clipboard.writeText(button.getAttribute("data-copy")).then(done, function () {});
      });
    });
  });
</script>
