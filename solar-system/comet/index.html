Comet

Sun Halley's Comet
Read me

Use it to show Halley's Comet, or another comet on an orbit you give it, in a page about the sky or the Solar System. The core works out where the comet is on a date and gives its tails as points for your own drawing. The glyph layer draws the comet in text characters on a canvas.

The core alone

  1. Copy comet.js next to your page.

  2. Add a canvas, load the script and draw the tails for a date. This draws the dust in yellow and the ion tail in blue, seen from the north of the Solar System at 1,000 pixels to an AU.

    <canvas id="tails" width="600" height="600" style="background: #000"></canvas>
<script src="comet.js"></script>
<script>
  const jd = Date.UTC(1986, 2, 10) / 864e5 + 2440587.5;   // 10 March 1986
  const pos = Comet.position(Comet.HALLEY, jd);           // [x, y, z] in AU
  const comet = Comet.at(Comet.HALLEY, jd, pos);
  const dust = Comet.dust(comet, { N: [0, 0, 1], Q: [1, 0, 0], E: [0, 1, 0] });
  const ion = Comet.ion(comet);
  const g = document.getElementById('tails').getContext('2d');
  g.fillStyle = '#ffd';
  for (let i = 0; i < dust.n; i++) {
    if (dust.w[i] > 0) g.fillRect(180 + dust.pos[i * 3] * 1000, 120 - dust.pos[i * 3 + 1] * 1000, 1, 1);
  }
  g.fillStyle = '#8bf';
  for (let i = 0; i < ion.n; i++) {
    g.fillRect(180 + ion.pos[i * 3] * 1000, 120 - ion.pos[i * 3 + 1] * 1000, 1, 1);
  }
</script>

The glyph look

  1. Copy comet.js and comet-glyphs.js from this folder, and glyph-renderer.js from ../glyph-renderer/, next to your page.

  2. Give the page a dark background with no margin.

    body { margin: 0; background: #050608; }
#sky { display: block; }

  3. Add a canvas, load the three scripts and draw the comet. This puts the nucleus near the top left of the window, with a tenth of an AU to the window's height.

    <canvas id="sky"></canvas>
<script src="glyph-renderer.js"></script>
<script src="comet.js"></script>
<script src="comet-glyphs.js"></script>
<script>
  const g = GlyphRenderer.create(document.getElementById('sky'));
  g.resize(innerWidth, innerHeight, devicePixelRatio, 10);
  const jd = Date.UTC(1986, 1, 9) / 864e5 + 2440587.5;    // 9 February 1986
  const pos = Comet.position(Comet.HALLEY, jd);
  g.clear();
  Comet.draw(g, {
    elements: Comet.HALLEY, jd: jd, pos: pos,
    x: g.W * 0.3, y: g.H * 0.25, scale: g.H * 10,
    frame: { N: [0, 0, 1], Q: [1, 0, 0], E: [0, 1, 0] }
  });
  g.compose();
  g.present();
</script>
