Glyph renderer

Read me

Use it to show a 3D shape, a logo or any other picture in text characters on your page. Your code gives the light at each point of a canvas, and the renderer picks a character and a colour for every cell. It is one script with no dependencies.

Add it to your page

  1. Copy glyph-renderer.js next to your page.

  2. Add a canvas and load the script at the end of the body. The characters are light, so give the canvas a dark background.

    <canvas id="art" style="background:#050608"></canvas>
<script src="glyph-renderer.js"></script>

  3. Make a renderer, size it and draw. The function you give draw gets a point in CSS pixels from the canvas's top left and writes the red, green and blue light there into out. This one draws a sphere lit from the upper left.

    <script>
  const g = GlyphRenderer.create(document.getElementById('art'));
  g.resize(320, 320, devicePixelRatio, 10);
  g.draw(function (x, y, out) {
    const dx = (x - 160) / 140, dy = (y - 160) / 140, z = 1 - dx * dx - dy * dy;
    if (z > 0) out[0] = out[1] = out[2] = Math.max(0, 0.6 * Math.sqrt(z) - 0.5 * dx - 0.5 * dy);
  });
</script>

Call draw again whenever the picture changes, for example once a frame. The full notes, options and API are in the README.
