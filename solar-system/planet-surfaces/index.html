Planet surfaces

EarthPreparing

Read me

Use it to give a planet, moon or star in your own scene its surface. It makes each body's map in the browser with no image files, and gives you the pixels as RGB bytes to draw on a canvas or to upload as a texture.

Add it to your page

  1. Copy surfaces.js next to your page. For the Earth, copy earth-map.js as well.

  2. Load them in the head, the Earth's map first.

    <script src="earth-map.js"></script>
<script src="surfaces.js"></script>

  3. Get a body's map at full size. The pixels are RGB bytes in d, row by row from the north pole, with east longitude running from −180° to 180° across.

    const map = Surfaces.texture("mars");
Surfaces.refine("mars", Infinity);
const { w, h, d } = map.levels[0];

  4. Copy the pixels into a canvas.

    const canvas = document.createElement("canvas");
canvas.width = w;
canvas.height = h;
const image = new ImageData(w, h);
for (let i = 0, j = 0; i < d.length; i += 3, j += 4) {
  image.data[j] = d[i];
  image.data[j + 1] = d[i + 1];
  image.data[j + 2] = d[i + 2];
  image.data[j + 3] = 255;
}
canvas.getContext("2d").putImageData(image, 0, 0);

  5. In three.js, use the canvas as the texture of a sphere.

    const texture = new THREE.CanvasTexture(canvas);
texture.colorSpace = THREE.SRGBColorSpace;
const mars = new THREE.Mesh(
  new THREE.SphereGeometry(1, 64, 32),
  new THREE.MeshStandardMaterial({ map: texture })
);
scene.add(mars);

  6. In plain WebGL, upload the bytes as they are. A shader then reads the map at u = 0.5 + longitude / 2π and v = 0.5 − latitude / π, in radians.

    gl.bindTexture(gl.TEXTURE_2D, gl.createTexture());
gl.pixelStorei(gl.UNPACK_ALIGNMENT, 1);
gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGB, w, h, 0, gl.RGB, gl.UNSIGNED_BYTE, d);
gl.generateMipmap(gl.TEXTURE_2D);

The README has the full API, including how to make a large map a slice at a time, the rings and the Earth's clouds.
