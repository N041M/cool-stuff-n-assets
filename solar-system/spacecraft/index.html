Spacecraft

Voyager

Read me

Use it to show a spacecraft at its real size on a page about space missions. The models are geometry with a ray function, so you can draw them in text characters with the glyph renderer or with your own drawing code.

Add it to your page

  1. Copy spacecraft.js and spacecraft-glyphs.js next to your page, and glyph-renderer.js from the glyph-renderer folder.

  2. Add a canvas with a dark background and load the three scripts at the end of the body, in this order.

    <canvas id="craft" style="background:#050608"></canvas>
<script src="glyph-renderer.js"></script>
<script src="spacecraft.js"></script>
<script src="spacecraft-glyphs.js"></script>

  3. Make a renderer, add a model to it and draw. frame turns the model and light points to the Sun, both as seen from the camera. This draws JWST with the Sun below its sunshield.

    <script>
  const g = GlyphRenderer.create(document.getElementById('craft'));
  g.resize(360, 360, devicePixelRatio, 10);
  const M = Spacecraft.models.jwst;
  g.clear();
  Spacecraft.draw(g, {
    model: M, x: g.W / 2, y: g.H / 2, metres: 2.4 * M.r / g.H,
    frame: { N: [0, 0.8, 0.6], Q: [0.6, -0.48, 0.64], E: [0.8, 0.36, -0.48] },
    light: [0.3, -0.8, -0.52]
  });
  g.compose();
  g.present();
</script>

Use the core alone

spacecraft.js on its own gives the models and a ray function for your own drawing code. Copy only that file. This draws Voyager on a 2D canvas with one ray a pixel, lit from the upper right.

<canvas id="craft" width="200" height="200" style="background:#000"></canvas>
<script src="spacecraft.js"></script>
<script>
  const M = Spacecraft.models.voyager, out = [0, 0, 0];
  const g = document.getElementById('craft').getContext('2d');
  for (let py = 0; py < 200; py++) for (let px = 0; px < 200; px++) {
    const cover = Spacecraft.ray(M, [(px - 100) / 6, (100 - py) / 6, 0], [0, 0, 1], [0.5, 0.3, 0.81], 1 / 6, out);
    if (cover > 0) {
      g.fillStyle = `rgb(${out.map((v) => Math.min(255, v / cover * 255)).join()})`;
      g.fillRect(px, py, 1, 1);
    }
  }
</script>
