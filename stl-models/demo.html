Read me

Use it on a shop or project page to let visitors turn and zoom a 3D-printable model before they download the file. The viewer sits in the page's flow and takes the width of the element you put it in. It needs WebGL, and the page must be served by a web server.

Add it to your page

  1. Copy demo.js, looks.js, demo.css and the folders fonts/, vendor/ and models/ next to your page.

  2. Add the import map, the stylesheet and the script to the head. The import map points three at the copy in vendor/three/.

    <script type="importmap">
  {
    "imports": {
      "three": "./vendor/three/three.module.js",
      "three/addons/": "./vendor/three/addons/"
    }
  }
</script>
<link rel="stylesheet" href="demo.css">
<script type="module" src="demo.js"></script>

  3. Copy the <main> element of demo.html into the body. Each item in its list is one model, so edit the list to show your own files.

One model on its own

  1. Copy vendor/three/ and one file from models/, and add the import map shown above to the head.

  2. Add a canvas and this script to the body. The files are Z-up, so the script turns the model to the Y-up of three.js.

    <canvas id="model"></canvas>
<script type="module">
  import * as THREE from "three";
  import { STLLoader } from "three/addons/loaders/STLLoader.js";
  import { OrbitControls } from "three/addons/controls/OrbitControls.js";

  const canvas = document.getElementById("model");
  const width = canvas.parentElement.clientWidth;
  const renderer = new THREE.WebGLRenderer({ canvas, antialias: true });
  renderer.setPixelRatio(Math.min(devicePixelRatio, 2));
  renderer.setSize(width, width * 3 / 4);

  const scene = new THREE.Scene();
  scene.add(new THREE.HemisphereLight(0xffffff, 0x555555, 2));
  const camera = new THREE.PerspectiveCamera(30, 4 / 3, 1, 5000);
  camera.add(new THREE.DirectionalLight(0xffffff, 1.5));
  scene.add(camera);
  const controls = new OrbitControls(camera, canvas);

  const geometry = await new STLLoader().loadAsync("models/servo-skull-drone.stl");
  geometry.rotateX(-Math.PI / 2);
  geometry.center();
  geometry.computeBoundingSphere();
  const material = new THREE.MeshStandardMaterial({ color: 0xb8b4ab, flatShading: true });
  scene.add(new THREE.Mesh(geometry, material));
  camera.position.set(0, 0, geometry.boundingSphere.radius * 4);

  renderer.setAnimationLoop(function () {
    controls.update();
    renderer.render(scene, camera);
  });
</script>
